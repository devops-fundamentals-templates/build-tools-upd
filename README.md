# Build Tools Task - Modern Stack 2026

## Overview

This project demonstrates a modern, production-ready web application built with **Vite**, **React**, **TypeScript**, **ESLint**, **Prettier**, and **Vitest**. It integrates seamlessly with a Gradle-based Spring Boot backend.

- **Styling**: Modern CSS with CSS Variables
- **Linting**: [ESLint](https://eslint.org/) - Code quality tool
- **Code Formatting**: [Prettier](https://prettier.io/) - Code formatter
- **Testing**: [Vitest](https://vitest.dev/) - Unit testing framework

- **Build Tool**: Gradle (Kotlin DSL)
- **Framework**: Spring Boot 2.7 with WebFlux
- **Language**: Kotlin
- **Runtime**: Java 11

## Part 2: Backend Integration with Gradle

### Requirements

- Java Development Kit (JDK) 11 or higher
- Node.js 16+ (for frontend build)

### Gradle Build Process

The `build.gradle.kts` is configured with the following tasks:

1. **`npmInstall`** - Installs frontend dependencies
2. **`compileUi`** - Builds the Vite TypeScript/React application
3. **`copyUi`** - Copies built assets to `src/main/resources/static`
4. **Automatic Integration** - `bootRun` task depends on `copyUi`

### Build and Run Commands

```bash
# Build the entire project (frontend + backend)
./gradlew build

# Run the application
./gradlew bootRun

# Run with clean build
./gradlew clean build bootRun
```

The application will be available at: **[http://localhost:8080](http://localhost:8080)**

## Troubleshooting

### Port already in use
```bash
# Dev server (default 3000)
npm run dev -- --port 3001

# Backend (default 8080)
./gradlew bootRun --args='--server.port=8081'
```

### Clear cache and rebuild
```bash
cd ui
rm -rf node_modules dist
npm install
npm run build
```

### Frontend not loading in backend
Ensure `copyUi` task completes successfully:
```bash
./gradlew compileUi --info
```
